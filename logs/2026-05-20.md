## [17:45] Fix Discover background flash (kitchen pattern hidden after load)
- Root cause: `discover-feed-client.tsx` wrapped the whole feed in an opaque floor (`background: var(--wc-floor, #1F1B19)`), painting over the global fixed `BackgroundDecorations` kitchen-pattern layer. During the loading skeleton (no opaque bg) the pattern showed; once the feed mounted, the floor covered it — the flash the user reported.
- Fix: set the feed root `background` to `transparent` so the global pattern (functional mode, 0.10 opacity) shows through, with section cards sitting on top and cutting it off locally (per user's request to keep the pattern but allow section cutoff).
- Investigated `bg-mode-context` / `SetBgMode`: forcing `hero` mode is futile because `AllRecipesClient` renders `SetBgMode mode="functional"` as a later sibling and overrides it. The 0.10 functional opacity matches the look the user liked, so no mode change was needed.
- Verified in browser (port 3002): feed root computed bg = rgba(0,0,0,0), pattern layer opacity = 0.1, pattern visible in uncovered areas.
- Files changed: `src/app/(app)/discover/discover-feed-client.tsx`
