## [02:15] Fix recipe description quality system

- Created `docs/recipe-description-guidelines.md` — canonical style guide defining structure (2-3 sentences, 40-55 words), 10 golden rules (no social metadata, no @ handles, no likes counts, no brand mentions, editorial tone), reference examples, and Claude prompt template
- Updated `src/app/api/recipes/[id]/extract/route.ts` — injected `DESCRIPTION_RULES` constant into all three Claude prompt paths (`structureCaption`, `generateFromMeta` hack branch, `generateFromMeta` premium-placeholder branch, and the generic fallback); also removed the raw `recipe.description` pass-through in the fallback prompt so scraped captions cannot bleed into descriptions
- Created `src/app/api/admin/fix-descriptions/route.ts` — batch admin POST route that: (1) fetches all recipes up to a configurable limit, (2) filters candidates using `isBadDescription()` heuristics (detects likes counts, hashtags, @ handles, placeholder text, emoji-heavy text), (3) rewrites each description via Claude Haiku with the guidelines, (4) updates the DB, (5) returns a full diff report; supports `dryRun`, `limit`, and `onlyPremium` params; protected by `ADMIN_SECRET` env var
